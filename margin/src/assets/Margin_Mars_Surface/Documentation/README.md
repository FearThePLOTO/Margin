# Margin — Mars Surface tileset

Every 16×16 tile for the Mars surface and caves. All of it is generated by
`tools/tilegen/gen.py`, so **edit the generator, not the PNGs**. Hand edits get
overwritten the next time it runs.

```
python tools/tilegen/gen.py .        # run from the Godot project root (needs Pillow + numpy)
```

The output is deterministic. Each run rewrites every PNG, the Godot TileSet
(`src/features/level_design/tilesets/mars_tileset.tres`), `atlas_index.json`,
`validation.txt` and everything in `Previews/`.

## Guarantees (checked on every run, see `validation.txt`)

- Every PNG is RGBA and its width and height are multiples of 16.
- Alpha is only 0 or 255. No anti-aliasing, blur, glow or gradients.
- Every opaque pixel uses one of the 52 colours in `tools/tilegen/palette.py`.
- Every non-empty 16×16 cell belongs to a TileSet tile, and no two tiles overlap.

## Using it in Godot

1. On a `TileMapLayer`, set **Tile Set** to `res://src/features/level_design/tilesets/mars_tileset.tres`.
2. **Terrain**: in the TileMap panel, open **Terrains** and pick a terrain set, then paint.
   Godot picks the right edge, corner or inner-corner tile and mixes in the random variants on its own.

   | Set | Terrain | Use |
   |---|---|---|
   | 0 | Mars Rock | surface ground, mesas, cliffs (strata body) |
   | 1 | Cave Rock | caves (cracked purple stone, orange rim light, matches Cave.jpg) |
   | 2 | Regolith Sand | dunes, loose ground |
   | 3 | Sand-Topped Rock | rock/sand transition (rock body, thick sand crust) |
   | 4 | Frost Rock | PermanentShadow zones (ice crust, icicles) |

   Each terrain is its own set, so two materials painted side by side each draw their own edges.
3. **Decor**: use a second `TileMapLayer` above the terrain for overlays such as cracks,
   minerals, sand covers, frost rime and grips. Those tiles are drawn to sit on top of a terrain tile.
4. **Collision**: physics layer 0 is set up on the terrain tiles (full squares), slopes
   (exact triangles), crater pieces (heightmap), ledges and grates (one-way, top 5 px),
   islands, crumbling platforms, the jump pad, the crate, metal panels and the climb walls.
   Everything else is decor with no collision.
5. **Hazard tags**: custom data layer `hazard` (StringName) holds `LavaZone`, `Spikes`, `heat`,
   `chill`, `radiation` or `LooseRegolith`. It's for reference and scripting only. The game still
   uses `hazard_zone.gd` Area2Ds for the real logic.

### Slopes
`Terrain/slopes.png` has one row per terrain (rock, cave, sand, sandy rock, frost).
Columns 0–5 are floors: 45° rising right, 45° rising left, 22.5° rising right (2 tiles),
22.5° rising left (2 tiles). Columns 6–11 are the same set for ceilings. Slopes aren't part of
the terrain autotile, so place them by hand. If the block next to a slope shows a side edge,
repaint that cell with the neighbouring terrain tile whose side faces the slope as solid.

### Multi-cell props
Props bigger than 16×16 (solar panel, O2 station, checkpoint, antenna, airlock, large boulders,
stalactites, crystals, vines) set `texture_origin` so the cell you paint is the **bottom-left**
cell of the prop. Ceiling props (stalactites, vines, ceiling anchor, ceiling crystals) anchor
**top-left** instead.

### Animated tiles
Lava and sludge (4 frames), heat and cryo vents (3), the jump pad (3), magma rock (2) and the
O2 station screen (2) loop as TileMap animations.
The checkpoint, tether anchor, lever and airlock door frames are **states** (off/on,
closed/open). Use them as `Sprite2D` regions or `AnimatedSprite2D` frames driven by script,
not as looping tiles. `atlas_index.json` lists every coordinate.

## Sheet contents

| File | Contents |
|---|---|
| `Terrain/terrain_{rock,cave,sandy_rock,frost}.png`, `Sand/terrain_sand.png` | 12×5 cells: the 47-tile blob set (rows 0–3) plus 3 interior and 2 top-edge random variants (row 4) |
| `Terrain/slopes.png` | 12×5: 45° and 22.5° floors and ceilings for every terrain |
| `Platforms/platforms.png` | one-way rock and cave ledges (L/M/R/single), metal grate (L/M/R/single), floating rocks, 2- and 3-wide floating islands, 4-wide crumbling platforms in 3 states |
| `Geological/geology.png` | boulders (S/M/L, cave), rock cluster, pebbles, 3 crack decals, minerals (hematite "blueberries", sulfate veins, iron oxide, teal ore vein), stalactites and stalagmites (S/L), magenta and teal crystals, 4×2 and 2×1 craters |
| `Vegetation/vegetation.png` | lichen, glow stalks, fungus caps, spore pod, tube worms, dry shrub, hanging vines, crystal moss |
| `Parkour/parkour.png` | tether anchors (floor and ceiling, idle/hooked), jump pad, climbable rock wall, loose-regolith wall, metal and natural grips |
| `Infrastructure/infrastructure.png` | solar panel, O2 station, checkpoint, O2 tank, antenna, weather sensor, drill rig, supply crate, sample canister, lamp post, airlock door, lever, pipes (h/v/4 elbows), trusses (X/v/h), 5 metal wall panels |
| `Hazards/hazards.png` | lava, radioactive sludge, magma rock, heat vent, cryo vent, rock and metal spikes (up/down/walls), ice crystals, frost rime, radiation ore, radioactive barrel, heat/cold/radiation/O2 signs |
| `Sand/sand_decals.png` | sand drifts (L/M/R), mound, sand covers for rock tops (L/M/R), edge spill, ripples |

`Previews/` holds 4× labelled contact sheets and two mock 320×180 scenes (`scene_surface.png`,
`scene_cave.png`). The labels exist **only** in the previews and never in the atlases. Godot
skips `Previews/` and `Documentation/` because of their `.gdignore` files.

## Palette
Deep purple-black shadows `#0e0912 #1a0f1f #2a1630`, burgundy `#3a1a2c #55212d`,
rust `#76291f #963823 #b84a28`, Mars orange `#d9652b #f2731f #f59a45`,
sandstone `#c98a52 #e2ad6e #f3cf96 #fbe8c4`, cave purple `#2b1b36 #3e2649 #573257 #744262`,
UI teal `#66d9c0` and orange `#f2731f`, plus small metal, frost, lava, radiation, crystal and
warning ramps. The full list is in `tools/tilegen/palette.py`.
